Code Basics

20 essential code snippets for beginners. HTML, CSS, JavaScript, and Python made simple.

HTML

Basic Structure

<!DOCTYPE html> <html> <head> <title>Page Title</title> </head> <body> <h1>Hello World</h1> </body> </html>

Hyperlink

<a href="https://example.com">Click here</a>

Image Tag

<img src="image.jpg" alt="Description" width="300">

Unordered List

<ul> <li>Item 1</li> <li>Item 2</li> <li>Item 3</li> </ul>

Form Input

<form action="/submit" method="post"> <input type="text" name="username" placeholder="Username"> <button type="submit">Submit</button> </form>

CSS

Center a Div

.center { display: flex; justify-content: center; align-items: center; height: 100vh; }

Hover Effect

.button:hover { background-color: #5A6B7A; transform: translateY(-2px); }

Responsive Grid

.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 20px; }

Box Shadow

.card { box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1); }

Dark Mode Toggle

body.dark-mode { background-color: #1A1C1F; color: #E0E4E8; }

JavaScript

Console Log

console.log('Hello, world!');

Alert Message

alert('This is a message.');

Event Listener

document.getElementById('btn').addEventListener('click', function() { // do something });

Fetch API

fetch('https://api.example.com/data') .then(response => response.json()) .then(data => console.log(data));

Local Storage

localStorage.setItem('key', 'value'); let data = localStorage.getItem('key');

Python

Print Statement

print("Hello, world!")

For Loop

for i in range(5): print(i)

If-Else

age = 18 if age >= 18: print("Adult") else: print("Minor")

Function Definition

def greet(name): return f"Hello, {name}"

List Comprehension

squares = [x**2 for x in range(10)]
