Windows Issues

Windows Won't Start

Problem: Computer turns on but Windows doesn't load.

Fix: Restart and press F8 repeatedly. Select "Safe Mode." If it works, run System Restore to undo recent changes. If not, use a Windows install USB to access Startup Repair.

Blue Screen of Death (BSOD)

Problem: Random blue screen with error codes.

Fix: Note the error code. Update all drivers (especially graphics). Run Windows Memory Diagnostic. Check for overheating. If it started after installing something, uninstall it.

Windows Update Stuck

Problem: Update stuck at a percentage for hours.

Fix: Wait 2-3 hours (sometimes it's slow). If truly stuck, force shutdown, restart, and run the Windows Update Troubleshooter. Clear the update cache by stopping wuauserv service and deleting C:\Windows\SoftwareDistribution.

File Explorer Crashing

Problem: File Explorer opens then immediately closes.

Fix: Open Task Manager, end "Windows Explorer" process, then restart it. If persists, run "sfc /scannow" in Command Prompt as admin. Clear File Explorer history.

Mac Issues

Mac Freezes Completely

Problem: Screen frozen, nothing responds.

Fix: Hold power button for 10 seconds to force shutdown. Wait 30 seconds, then restart. Reset NVRAM by holding Cmd+Option+P+R on startup. Check for disk errors in Disk Utility.

Mac Running Slow

Problem: Everything takes forever to load.

Fix: Check Activity Monitor for processes using high CPU. Clear caches. Close unused apps. Free up disk space (aim for 20% free). Consider adding more RAM if possible.

App Won't Open on Mac

Problem: Click app icon but it doesn't launch.

Fix: Force quit the app (Cmd+Option+Esc). Check if it's blocked by Gatekeeper (System Settings > Privacy & Security). Try reinstalling the app. Check Console for error messages.

Mac Won't Connect to Wi-Fi

Problem: Wi-Fi icon shows but no connection.

Fix: Turn Wi-Fi off and on. Forget the network and rejoin. Reset the SMC (System Management Controller). Renew DHCP lease in Network settings.

Internet / Network

Wi-Fi Connected But No Internet

Problem: Connected to router but can't browse.

Fix: Restart modem and router. Check if other devices work (isolates the problem). Run "ipconfig /flushdns" in Command Prompt. Change DNS to 8.8.8.8. Contact ISP if nothing works.

Slow Internet Speed

Problem: Pages load slowly, buffering constantly.

Fix: Test speed at speedtest.net. Compare to your plan. Move closer to router or use ethernet. Restart router. Check for background downloads. Update router firmware.

DNS Server Not Responding

Problem: "DNS server not responding" error.

Fix: Flush DNS: open Command Prompt and type "ipconfig /flushdns". Change DNS servers to 8.8.8.8 and 8.8.4.4 (Google). Restart your router. Update network adapter drivers.

Ethernet Not Working

Problem: Cable plugged in but no connection.

Fix: Check cable isn't damaged. Try different port on router. Run network troubleshooter. Update network adapter driver. In Device Manager, disable and re-enable the adapter.

Browser Problems

Browser Running Slow

Problem: Pages take forever to load in browser.

Fix: Clear browsing data (cache, cookies). Disable unused extensions. Check for browser updates. Close unused tabs. Try a different browser to isolate the issue.

Chrome Crashes Constantly

Problem: Chrome randomly closes or freezes.

Fix: Update Chrome. Clear cache. Disable extensions one by one to find culprit. Reset Chrome settings. If all fails, uninstall and reinstall Chrome.

Can't Clear Browser History

Problem: History won't delete.

Fix: Check if browser is synced (Google account, Firefox sync). Clear sync data. Try using keyboard shortcut (Ctrl+Shift+Delete). Use CCleaner for stubborn data. Check if a policy is blocking clearing (school/work computers).

Pop-up Ads Everywhere

Problem: Constant pop-ups even when not browsing.

Fix: This is likely adware. Install Malwarebytes and run a full scan. Remove suspicious browser extensions. Reset browser settings. Check installed programs for anything you didn't install.

Software Crashes

Program Won't Open

Problem: Double-click but nothing happens.

Fix: Check Task Manager to see if it's running but hidden. Right-click and "Run as Administrator". Reinstall the program. Check for compatibility issues with your OS version.

Program Keeps Freezing

Problem: App works for a while then freezes.

Fix: Update the program. Check if your computer meets minimum requirements. Close other programs to free up RAM. Update your GPU drivers (especially for creative apps).

Software Install Fails

Problem: Installation errors midway through.

Fix: Run installer as administrator. Check for enough disk space. Temporarily disable antivirus. Download a fresh copy of the installer. Check Windows Installer service is running.

App Missing After Update

Problem: Program disappeared after system update.

Fix: Check if it's been moved (search in Start menu). Look in Program Files folders. Check if it was uninstalled by the update. Reinstall from original source.

Slow Computer

Computer Takes Forever to Start

Problem: Boot time is 5+ minutes.

Fix: Disable startup programs (Task Manager > Startup). Update to SSD if you have HDD. Clean up disk (Disk Cleanup tool). Check for malware. Consider fresh Windows install.

Everything Is Slow

Problem: All programs lag, even simple tasks.

Fix: Check RAM usage in Task Manager. Close unused apps. Run malware scan. Check disk health (CrystalDiskInfo). Consider upgrading RAM or switching to SSD.

High CPU Usage

Problem: Fan runs constantly, CPU near 100%.

Fix: Open Task Manager, sort by CPU. End task on suspicious processes. Check for mining malware. Update Windows. Clean dust from vents.

Low Memory Warnings

Problem: "Your computer is low on memory" popup.

Fix: Close unused programs. Increase virtual memory (System Properties > Advanced > Performance Settings > Advanced > Virtual Memory). Add more RAM if possible.

Printer Issues

Printer Not Detected

Problem: Computer can't find the printer.

Fix: Check USB cable or Wi-Fi connection. Restart printer and computer. Remove printer from Devices and re-add it. Update printer drivers from manufacturer's website.

Printer Prints Blank Pages

Problem: Paper comes out blank.

Fix: Check ink/toner levels. Run printer head cleaning utility. Make sure you removed protective tape from new cartridge. Try printing a test page directly from printer.

Paper Jam

Problem: Paper stuck inside printer.

Fix: Turn off and unplug printer. Open all access panels. Pull paper out gently in the direction it feeds. Check for small pieces left behind. Reset printer.

Printer Offline

Problem: Status shows "offline" but printer is on.

Fix: Right-click printer > "Use Printer Online" (uncheck "Use Printer Offline"). Restart print spooler service. Re-add the printer. Check network connection for network printers.

Email Problems

Can't Send Emails

Problem: Emails stuck in outbox.

Fix: Check internet connection. Verify outgoing server settings (SMTP). Check if email is too large. Restart email client. Check if account needs re-authentication.

Not Receiving Emails

Problem: No new emails coming in.

Fix: Check junk/spam folder. Check email filters/rules. Verify incoming server settings. Check storage quota (full mailbox blocks new mail). Refresh the inbox.

Email Won't Sync

Problem: Emails on phone don't match computer.

Fix: Check sync settings in email app. Force manual sync. Remove account and re-add it. Update email app. Check account settings on all devices.

Forgot Email Password

Problem: Can't log into email account.

Fix: Use "Forgot Password" link. Check recovery email or phone. Answer security questions. Contact email provider support if all else fails.

Storage Issues

Disk Almost Full

Problem: "Low disk space" warning.

Fix: Run Disk Cleanup. Delete unused programs. Clear downloads folder. Empty recycle bin. Move large files to external drive. Use Storage Sense (Windows 10/11).

External Drive Not Detected

Problem: USB drive plugged in but nothing happens.

Fix: Try different USB port. Check Device Manager for unrecognized device. Try on another computer. Check if drive needs power (larger drives). Use Disk Management to assign letter.

Can't Delete a File

Problem: "File is in use" or "Access denied" when deleting.

Fix: Close programs that might use it. Restart computer and try again. Use "Unlocker" tool. Take ownership of the file. Try deleting in Safe Mode.

USB Drive Write-Protected

Problem: Can't copy files to USB, says write-protected.

Fix: Check for physical write-protect switch on the drive. Use Diskpart to remove write protection. Scan for malware. Format the drive as a last resort (data will be erased).

Display Problems

Screen Flickering

Problem: Display flickers or flashes.

Fix: Check cable connection. Update GPU drivers. Try different refresh rate. Check if it happens in Safe Mode (isolates driver issue). Try different monitor to isolate problem.

Wrong Screen Resolution

Problem: Everything looks stretched or tiny.

Fix: Right-click desktop > Display Settings. Set to recommended resolution. Check GPU driver is installed. Try different scaling setting.

Second Monitor Not Detected

Problem: External monitor shows nothing.

Fix: Check cable is connected. Press Windows+P and select "Extend" or "Duplicate". Check input source on monitor. Update GPU drivers. Try different port.

Screen Went Black

Problem: Screen suddenly black but computer running.

Fix: Check monitor power. Try different cable. Press Ctrl+Shift+Windows+B to restart graphics driver. Try external monitor on laptop. Check brightness settings.

Audio Issues

No Sound at All

Problem: Computer makes no sound.

Fix: Check volume isn't muted. Check correct output device is selected. Update audio drivers. Check speaker/headphone connection. Restart computer.

Sound Is Distorted

Problem: Audio crackles or sounds bad.

Fix: Check speaker/headphone quality. Update audio drivers. Check audio enhancements are off. Try different audio device. Check cable connections.

Microphone Not Working

Problem: No one can hear you in calls.

Fix: Check mic isn't muted in app. Check Windows privacy settings for mic access. Test mic in Sound settings. Update audio drivers. Check mic is plugged into correct port.

Headphones Not Detected

Problem: Plug in headphones but sound still from speakers.

Fix: Check headphone jack is fully inserted. Try different headphones. Check audio settings for output device. Update audio drivers. Check for debris in jack.

Keyboard / Mouse

Keyboard Not Typing

Problem: Some or all keys don't work.

Fix: Check connection (USB or Bluetooth). Try different USB port. Clean under keys. Update keyboard driver. Check keyboard language settings.

Mouse Not Moving

Problem: Cursor stuck or mouse unresponsive.

Fix: Check USB connection. Try different port. Replace batteries (wireless). Clean sensor. Update mouse driver. Try on different computer.

Double-Click Problem

Problem: Single click acts like double-click.

Fix: Check mouse settings in Control Panel. Adjust double-click speed. Clean the mouse button. Try different mouse to isolate. Consider replacing if hardware issue.

Bluetooth Device Won't Connect

Problem: Bluetooth keyboard/mouse won't pair.

Fix: Make sure device is in pairing mode. Turn Bluetooth off and on. Remove old pairing and re-pair. Check battery level. Update Bluetooth drivers.

Phone Issues

Phone Battery Drains Fast

Problem: Battery dies quickly even with light use.

Fix: Check battery usage in settings. Disable background app refresh. Reduce screen brightness. Turn off location when not needed. Check for battery-draining apps.

Phone Won't Charge

Problem: Plug in charger but battery doesn't increase.

Fix: Try different cable and charger. Clean charging port (carefully with toothpick). Check for lint in port. Try wireless charging if available. Restart phone.

Phone Running Slow

Problem: Apps take forever to open, lag everywhere.

Fix: Clear app caches. Uninstall unused apps. Free up storage. Update the OS. Consider factory reset as last resort (back up first).

Phone Overheating

Problem: Phone gets very hot during use.

Fix: Remove case while charging. Close background apps. Turn off while charging. Avoid using in direct sunlight. Check for apps using excessive CPU.

Security / Virus

Computer Has a Virus

Problem: Pop-ups, slow performance, unexpected behavior.

Fix: Disconnect from internet. Boot in Safe Mode. Run Malwarebytes full scan. Run Windows Defender scan. Consider reinstalling Windows if severe.

Ransomware Detected

Problem: Files encrypted, ransom note displayed.

Fix: DO NOT pay the ransom. Disconnect from network immediately. Contact IT professional. Check if you have backups. Report to authorities.

Account Hacked

Problem: Can't access account, password changed.

Fix: Use "Forgot Password" immediately. Check recovery email. Change passwords on all linked accounts. Enable two-factor authentication. Check sent folder for suspicious emails.

Phishing Email Received

Problem: Suspicious email asking for info or with links.

Fix: DO NOT click any links. DO NOT reply. Mark as spam/phishing. Delete the email. If you did click, change passwords immediately and run malware scan.

Other Common Fixes

Computer Won't Shut Down

Problem: Shutdown hangs, computer stays on.

Fix: Wait 5-10 minutes (sometimes updates install during shutdown). Force shutdown by holding power button 10 seconds. Check for pending updates. Disable fast startup.

Forgot Windows Password

Problem: Can't log into Windows account.

Fix: Use password reset disk if you made one. Use Microsoft account recovery. Boot from Windows install USB and use Command Prompt to reset password. Last resort: reinstall Windows.

Date and Time Wrong

Problem: Clock shows wrong time or date.

Fix: Check time zone settings. Sync with internet time server. Replace CMOS battery if time resets every boot. Set manually if no internet.

Random Restarts

Problem: Computer restarts without warning.

Fix: Check for overheating (clean fans, check thermal paste). Check RAM with memory test. Update all drivers. Check power supply. Check for malware.
